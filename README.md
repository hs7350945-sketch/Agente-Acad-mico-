# 🤖 Assistente Acadêmico

## Sobre o projeto

O Assistente Acadêmico é um projeto desenvolvido com recursos de inteligência artificial para auxiliar estudantes na criação, organização e revisão de trabalhos acadêmicos.

## 🎯 Objetivo

O projeto tem como objetivo facilitar o desenvolvimento de atividades acadêmicas, reunindo recursos para organizar, revisar e salvar conteúdos em um único ambiente.

## 🚀 Principais funcionalidades

- Login de usuário
- Criação e organização de conteúdos
- Salvamento de trabalhos
- Histórico de conteúdos
- Exclusão de conteúdos
- Interface em modo claro e escuro

## 🤖 Inteligência Artificial

O projeto utiliza recursos de inteligência artificial para auxiliar na criação e revisão de conteúdos acadêmicos, tornando o desenvolvimento das atividades mais organizado e prático.

## 🎨 Experiência do usuário

O projeto possui foco em uma experiência simples e intuitiva, com organização dos conteúdos e opções de visualização em modo claro e escuro.

## 🛠️ Projeto

Este projeto foi desenvolvido como parte da minha formação em Engenharia de Software, envolvendo inteligência artificial, organização de informações e criação de uma solução digital.
